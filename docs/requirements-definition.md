# 計算迷宮（Calculation Labyrinth）- 要件定義書

> 脳トレ * ローグライク * 中世RPG世界観のスマホゲームアプリ

## 1. プロジェクト概要

### 1.1 コンセプト
- 主人公「あかね」は冒険家
- 「あかね」が求めるのは万物の理が封じられている宝玉「理の宝玉」
- 「理の宝玉」は「計算迷宮　アリスメア」（以下アリスメア）と呼ばれる迷宮の地下深くにあると噂されている
- 「アリスメア」に入ると「ガーディアン」が計算問題を仕掛けてくる
- しかも「ガーディアン」の計算問題を間違ったり、制限時間以内に解けなかったりすると部屋に「眠りの霧」があふれはじめ、充満すると眠ってしまう
- 眠ったら迷宮で手に入れた「遺物」も含め、すべてを失い、迷宮の入り口に戻される
- 主人公「あかね」は「理の宝玉」を取ることができるのか！？

### 1.2 ゲーム内容
- 合計100問の計算問題が出題される
- それらの問題は20問ずつ5段階にわけて出題される
- プレイヤーが有利になったり、スコアを伸ばすことができる「遺物」がそれぞれの段階の最初に３つ提示される。その中からプレイヤーは１つを選択する。
- プレイヤーが問題を間違えたり、問題の制限時間が来たりした場合に「意識」を１つ失う。意識が0になると眠ってしまう。
- それらの「遺物」を駆使して、意識が0にならないように計算問題を解き続けて、最高スコアを目指す！

### 1.3 ターゲットユーザー

1ラン当たりのプレイ時間は5~10分（通常モードを基準とする）

#### 1.3.1 小学生
- 計算の練習として利用
- 100マス計算を行う感覚でプレイ

#### 1.3.2 20代後半~30代
- メイン層にしたいターゲット
- スコアアタックを行うためにプレイ

#### 1.3.3 60~70代
- ボケ防止
- 脳トレ感覚でプレイ

## 2. ゲームシステム概要
### 2.1 スタートメニュー
ゲーム開始時にユーザーが選択

| メニュー | 詳細 |
|--------|---------|
| **ストーリーモード** | あかねを中心としたストーリーを展開していく。チュートリアルのようなもの。20分くらいで終わるものを想定。ランキングにも反映されない。 |
| **スコアモード** | ストーリーに関係なく、様々なモードが用意されている。ストーリーモードやスコアモードを遊ぶと手に入る「コイン」を利用して解放していく。 |
| **ランキング** | スコアモードのランキングを見ることができる |
| **図鑑** | 出会った遺物とガーディアンを見ることができる |
| **ショップ** | 遺物がパッケージで売っている。遺物パッケージはジェムで購入することができる |
| **設定** | BGM/SEの調整などゲームの設定を調整できる。利用規約・プライバシーポリシー・問い合わせもここから確認できる |

### 2.2 スコアモードの詳細

#### 2.2.1 モード一覧
| モード | 詳細 |
|--------|---------|
| **お手軽モード** | 20問*3段階で60問を解ききるモード |
| **通常モード** | 20問*5段階で100問を解ききるモード |
| **長旅モード** | 20問*10段階で200問を解ききるモード |
| **遺物なしモード** | 20問*5段階で100問を解ききるモード。ただし遺物はなし。完全実力勝負 |
| **エンドレスモード** | 20問*無限でプレイヤーの意識が0になるまで解き続けるモード |

#### 2.2.2 難易度一覧
| 難易度 | 特徴 |
|--------|---------|
| **簡単** | 加減算のみ、１桁の計算中心 |
| **普通** | 加減乗算、２桁の計算も含む（乗算を除く）|
| **難しい** | 加減乗除算、２桁の計算も含む |
| **鬼難** | 加減乗除算、マイナスも含む |

#### 2.2.3 プレイ形式

| 形式 | 詳細 |
| ----- | ----- |
| **4択形式** | 4つの選択肢から正しいものを1つ選ぶ。手軽。 |
| **入力形式** | 答えを入力する。本格派向け。 |

### 2.3 ゲーム基本ルール

通常モード・普通・4択形式を基に、基本的なルールを整理していきます。

#### 2.3.1 構成
| 項目 | 内容 |
| ---- | ---- |
| 総問題数 | 100問 |
| 段階数 | 5段階 |
| 1段階当たりの問題数 | 20問 |
| 遺物の獲得回数 | 5回（各段階の開始時）|
| 意識の初期値 | 3 |
| 目覚めの鈴 | 1つ |

#### 2.3.2 進行の流れ
1. 段階の開始時に「遺物」が3つ提示される。その中から1つを選ぶ
2. 計算問題を20問続けて解く
3. 1~2を5回繰り返す
4. 計算問題を100問解き終わるとクリア

#### 2.3.3 遺物選択
- 各段階の一番最初に遺物を選択できる
- 異なる遺物が３種類提示される
- そのラン中に出た遺物は一度提示されたら二度と出ない
- プレイヤーは３種類の遺物から１つ選択する

#### 2.3.4 ガーディアン
- 各段階でガーディアンが登場する
- 能力を持たないガーディアンもいれば、能力を持つガーディアンもいる（仮）
- ガーディアンは問題を20問出す
- 20問解ききったら倒される。

#### 2.3.5 解答形式
- 1問ごとに制限時間がある
- 制限時間は5秒である
- 制限時間以内に解答を行う

#### 2.3.6 正誤判定 / 意識
- 解答後、すぐに正誤判定が行われる
- 制限時間が来たら不正解になる
- 不正解の場合、意識が１減る
- 正解・不正解にかかわらず、意識が1以上残っていれば次の問題に進む
- 意識が0になると眠ってしまう
- 「目覚めの鈴」が残っていれば、鈴が鳴って目を覚まし、再開できる
- 目を覚ますとスコアが70%（仮）になり、意識が2戻る。鈴は失われる
- 鈴が残っていない、または使わなかった場合はそこでランが終了する

#### 2.3.7 終了条件

| 結果 | 条件 | そのあと |
| ----- | ----- | ----- |
| **クリア** | 100問を解ききる | スコアが確定する |
| **眠り** | 意識が0になり、目覚めの鈴を使わなかった、または鈴が残っていない | その時点までのスコアが確定する |

どちらの場合もスコアは記録される。

#### 2.3.8 スコア

- 問題に正解するとスコアが加算される
- 獲得した「遺物」によって加算のされ方が変わる
- スコアが最終的なランキングの順位に利用される

1問ごとのスコアは、加算項目の合計に倍率項目を掛けて求める。

```
1問のスコア = （加算項目の合計） × （倍率項目の積）
```

| 項目 | 種別 | 内容 | 値 |
| ----- | ----- | ----- | ----- |
| ベース | 加算 | 正解1問ごとに与えられる固定点 | 未定 |
| 速度ボーナス | 加算 | 制限時間の残りに応じて加算される | 未定 |
| 連続正解 | 倍率 | 連続正解数に応じた倍率 | 未定 |
| 難易度 | 倍率 | 選んだ難易度に応じた倍率 | 未定 |
| フロア | 倍率 | フロアに応じた倍率 | 未定 |
| 遺物 | 加算 / 倍率 | 獲得した遺物の効果による | 未定 |

ラン全体のスコアは、各問のスコアの合計に以下を加えたもの。

| 項目 | 種別 | 内容 | 値 |
| ----- | ----- | ----- | ----- |
| クリアボーナス | 加算 | 100問を解ききったときに加算される | 未定 |

### 2.4 遺物

プレイヤーが有利になったり、スコアを伸ばしたりする効果を持つ。ランの中だけ有効で、ランが終わると失われる。

#### 2.4.1 獲得

- 各段階の開始時に3種類が提示され、その中から1つを選ぶ
- 一度提示された遺物は、そのプレイ中に二度と提示されない
- 遺物なしモードでは遺物を獲得しない。完全実力勝負。

#### 2.4.2 効果の種別

以下のような効果を持つ遺物がある

| 種別 | 特徴 |
| ---- | ---- |
| スコア | スコアの引き上げを行える |
| 制限時間 | 時間を操作できる |
| 意識 | 意識を操作できる |
| 連続正解 | 連続正解の倍率を上げられる |
| 問題 | 問題をいじることができる |
| ガーディアン | ガーディアンに影響を与える |
| フロア | フロアに影響を与える |

#### 2.4.3 レアリティ

遺物にはレアリティがある。レアリティによって、遺物の出現のしやすさが変わる。

| レアリティ | 表記 |
|---|---|
| ノーマル | ★ |
| レア | ★★ |
| スーパーレア | ★★★ |

フロアによって、遺物のレア度ごとの出現率は変わる

#### 2.4.4 遺物パッケージ

- 遺物はショップで「遺物パッケージ」として購入できる
- 遺物パッケージを購入すると、パッケージ内に入っている遺物がラン中に出現するようになる。
- 「遺物パッケージ」は遊びの幅を広げるため。Pay-to-winにはしない

### 2.5 ガーディアン
各段階に登場し、プレイヤーに計算問題を出す存在。

- 各段階で1体が登場する
- 1体につき20問を出題する
- 20問を解き終えると倒される
- 能力を持たないガーディアンと、能力を持つガーディアンがいる

※あまり深く設定は決めていない。

### 2.6 ストーリーモード

- あかねを中心としたストーリーを展開する
- チュートリアルを兼ねる
- 通常モード・4択形式を採用
- ランキングには反映されない

**未定。** 全体の構成（何ラン分で構成するか）、分量、クリア報酬。2.1 に記載している「20分くらい」は現時点の想定値。

## 3. ゲーム外の要素

### 3.1 通貨

| 通貨 | 入手 | 使い道 |
| ----- | ----- | ----- |
| **コイン** | ストーリーモード・スコアモードを1ラン終わると入手 | モード・難易度の解放 / 遺物パッケージの購入 |
| **ジェム** | 課金 | モード・難易度の解放 / 遺物パッケージの購入 / 広告解除 |

### 3.2 モード・難易度の解放

- スコアモードはお手軽モード/通常モードの簡単・普通は最初から解放されている。
- それ以外のモードと難易度はコインかジェムを使って解放する。

### 3.3 ショップ/課金
- 課金対象としては以下
    - 広告解除
    - 遺物パッケージの購入
    - スコアモード・難易度の解放
- 課金対象はすべてジェム（仮想通貨）で管理する
- ジェムは課金して購入する

### 3.4 広告
- 広告として以下を考える
    - **バナー広告**: 常時一番下に出す
    - **動画広告**: 1ラン終了後に見る広告。見終わった後にコインがもらえる。
    - **リワード広告**: 目覚めの鈴を使うときに視聴する。目覚めのルールは 2.3.6 を参照

※広告解除を購入した場合、広告を飛ばして、広告後の効果をもらうことができる。

### 3.5 ランキング
- ランキングはモード・難易度・プレイ形式の組み合わせごとに分ける
- ローカルランキングとグローバルランキングを用意する
- 集計期間は全期間・ウィークリー・デイリーの３つ
- 名前はオプションから付ける。つける前だと名無し冒険者になる

#### 3.5.1 ローカルランキング
- 自分のBest5の順位が出力される
- 順位とスコアを表示（そのほかランの詳細を出力するかも、まだ未定）

#### 3.5.2 グローバルランキング
- 世界のBest100の順位と、自分の最高スコアの現在順位が出力される
- 順位と名前とスコアを表示（そのほかランの詳細を出力するかも、まだ未定）

### 3.6 図鑑

- 出会った遺物とガーディアンが記録されていく
- 長く遊んでもらうための収集要素として用意する

## 4. アカウント周り
### 4.1 アカウント引継ぎ
- 初回起動時は匿名アカウントで自動的にログインする
- ログインは必須とする
- ユーザーIDを表示しておく
- ユーザーIDとパスワードを設定すると、引き継ぎと複数端末での利用ができるようになる

### 4.2 中断と再開
- 中断はできない。破棄される。（公平性を保つため）

### 4.3 アカウント削除
- アカウントを削除できるようにする
- 削除するとコイン・ジェム・解放状況・図鑑・ベストスコアが消える
- ランキングに登録済みのスコアも削除する

## 5. 非機能要件
### 5.1 対応プラットフォーム
iOS予定

### 5.2 通信要件

ゲームのプレイ中は通信を必要としない。データの保存・取得と広告表示にのみ通信を使う。

以下の場合に通信が必要。

#### 5.2.1 起動時
以下で必要想定
- ユーザーのログイン
- ユーザーデータの取得
- マスターデータの取得（不正防止）

通信できなかった場合はエラーを出して再接続してもらうようにする

#### 5.2.2 ランキング登録
- DBにランのデータを保存する際に利用
- 通信できなかった場合はエラーを出して再接続するか、登録せずに終了を選べるようにする

#### 5.2.3 ジェム購入・遺物パッケージ購入・モード解放
- DBのデータを更新する際に利用
- 通信できなかった場合はエラーを出して再接続するか、タイトルに戻るを選べるようにする

#### 5.2.4 広告
- 広告の表示に利用
- バナー広告が取得できない場合は問題なく動作することにする
- リワード広告が取得できない場合はエラーを出して報酬なしで進めるか、タイトルに戻すかを選ぶ
- 動画広告が取得できない場合はエラーを出して追加のコインを与えることなくタイトルに戻す

### 5.3 不正防止
- スコアはサーバ側で検証したうえでランキングに登録する
- 検証のため、ランのデータの一部をBEで作成、保存し、スコアを比較検証する
- 不正下ユーザーに対しては警告を鳴らし、5回以上不正したユーザーについてはサイレントBAN（ランキングから全て除外、ランキングに載らないようにする）する

### 5.4 対応言語
- 日本語のみ
