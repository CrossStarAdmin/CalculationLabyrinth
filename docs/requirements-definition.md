# 計算迷宮（Calculation Labyrinth）- 要件定義書

脳トレ × ローグライク × 中世RPG世界観のスマホゲームアプリ。

## 1. プロジェクト概要

### 1.1 コンセプト
段階ごとに遺物を1つ選び、意識が0になる前に計算問題を解ききって最高スコアを目指す。

- 主人公「あかね」は冒険家。万物の理が封じられた宝玉「理の宝玉」を求める
- 理の宝玉は「計算迷宮 アリスメア」（以下アリスメア）の地下深くにある
- アリスメアではガーディアンが計算問題を出す。誤答・時間切れで部屋に「眠りの霧」が広がり、充満すると眠る
- 眠ると遺物を含むすべてを失い、迷宮の入り口に戻される

### 1.2 ターゲットユーザー
メインは20代後半〜30代。1ランのプレイ時間は5〜10分（通常モード基準）。

| 層 | 遊び方 |
| --- | --- |
| 小学生 | 計算練習。100マス計算の感覚 |
| 20代後半〜30代（メイン） | スコアアタック |
| 60〜70代 | 脳トレ・ボケ防止 |

## 2. ゲームシステム

### 2.1 スタートメニュー

| メニュー | 内容 |
| --- | --- |
| **ストーリーモード** | あかねのストーリーを進める（2.6） |
| **スコアモード** | 各種モードでスコアを競う。コイン・ジェムで解放する（3.2） |
| **ランキング** | スコアモードのランキングを見る（3.5） |
| **図鑑** | 出会った遺物とガーディアンを見る（3.6） |
| **ショップ** | 遺物パッケージ等を購入する（3.3） |
| **オプション** | BGM/SE等の設定、利用規約・プライバシーポリシーの確認。モーダルで表示する |

### 2.2 スコアモード

| モード | 内容 |
| --- | --- |
| **お手軽モード** | 20問 × 3段階 = 60問 |
| **通常モード** | 20問 × 5段階 = 100問 |
| **長旅モード** | 20問 × 10段階 = 200問 |
| **遺物なしモード** | 20問 × 5段階 = 100問。遺物を獲得しない |
| **エンドレスモード** | 20問 × 無限。意識が0になるまで続く |

| 難易度 | 出題範囲 |
| --- | --- |
| **簡単** | 加減算、1桁中心 |
| **普通** | 加減乗算、2桁を含む（乗算を除く） |
| **難しい** | 加減乗除算、2桁を含む |
| **鬼難** | 加減乗除算、マイナスを含む |

| プレイ形式 | 内容 |
| --- | --- |
| **4択形式** | 4つの選択肢から1つ選ぶ |
| **入力形式** | 答えを入力する |

### 2.3 基本ルール
通常モード・普通・4択形式を基準とする。段階ごとに遺物を選び、20問を解く流れを5回繰り返す。

| 項目 | 内容 |
| --- | --- |
| 総問題数 | 100問（20問 × 5段階） |
| 遺物の獲得 | 各段階の開始時に1つ（2.4） |
| 制限時間 | 1問5秒。時間切れは不正解 |
| 意識の初期値 | 3 |
| 目覚めの鈴 | 1つ |

- 解答後すぐに正誤判定する。不正解なら意識が1減る
- 意識が1以上あれば次の問題に進む。0になると眠る
- 眠ったとき鈴が残っていれば、使うと目覚める。スコアが70%になり、意識が2戻り、鈴を失う
- 鈴を使わない・残っていない場合はランが終了する

| 結果 | 条件 |
| --- | --- |
| **クリア** | 全問を解ききる |
| **眠り** | 意識が0になり、鈴を使わない・残っていない |

どちらの場合もその時点のスコアを確定し、記録する。

### 2.4 スコア
正解するとスコアが加算される。スコアはランキングの順位に使う。

```
1問のスコア = （加算項目の合計） × （倍率項目の積）
ランのスコア = 各問のスコアの合計 + クリアボーナス
```

| 項目 | 種別 | 内容 |
| --- | --- | --- |
| ベース | 加算 | 正解1問ごとの固定点 |
| 速度ボーナス | 加算 | 制限時間の残りに応じた点 |
| 連続正解 | 倍率 | 連続正解数に応じた倍率 |
| 難易度 | 倍率 | 難易度に応じた倍率 |
| フロア | 倍率 | フロアに応じた倍率 |
| 遺物 | 加算 / 倍率 | 遺物の効果による |
| クリアボーナス | 加算（ラン全体） | クリア時に加算 |

### 2.5 遺物
スコアを伸ばしたり有利になったりする効果を持つ。そのランの間だけ有効。

- 各段階の開始時に異なる3種類が提示され、1つを選ぶ
- 一度提示された遺物は、そのラン中に再提示しない
- レアリティ（★ノーマル / ★★レア / ★★★スーパーレア）で出現率が変わる。出現率はフロアごとに変わる
- ショップの遺物パッケージを購入すると、パッケージ内の遺物がラン中に出現するようになる。課金の有無で有利不利が生じないバランスにする

| 効果の種別 | 作用 |
| --- | --- |
| スコア | スコアを引き上げる |
| 制限時間 | 時間を操作する |
| 意識 | 意識を操作する |
| 連続正解 | 連続正解の倍率を上げる |
| 問題 | 問題を操作する |
| ガーディアン | ガーディアンに影響する |
| フロア | フロアに影響する |

### 2.6 ガーディアン
各段階に1体登場し、20問を出題する。20問を解き終えると倒される。

- 能力を持つガーディアンと持たないガーディアンがいる

### 2.7 ストーリーモード
あかねを中心としたストーリーを展開し、チュートリアルを兼ねる。

- 通常モード・4択形式で遊ぶ
- ランキングには反映しない

## 3. ゲーム外の要素

### 3.1 通貨

| 通貨 | 入手 | 使い道 |
| --- | --- | --- |
| **コイン** | ストーリーモード・スコアモードを1ラン終える | モード・難易度の解放 / 遺物パッケージ |
| **ジェム** | 課金 | モード・難易度の解放 / 遺物パッケージ / 広告解除 |

### 3.2 モード・難易度の解放
お手軽モード・通常モードの簡単・普通を初期解放とする。それ以外はコインかジェムで解放する。

### 3.3 ショップ
遺物パッケージ・ジェム・広告解除を販売する。

### 3.4 広告

| 広告 | タイミング | 効果 |
| --- | --- | --- |
| **バナー広告** | 常時、画面最下部 | なし |
| **動画広告** | 1ラン終了後 | 視聴後にコインを獲得 |
| **リワード広告** | 目覚めの鈴を使うとき | 視聴後に目覚める |

広告解除の購入者は広告を見ずに効果を受け取る。

### 3.5 ランキング
ボード（モード × 難易度 × プレイ形式）× 集計期間（全期間 / ウィークリー / デイリー）ごとに順位を出す。

| 種類 | 表示内容 |
| --- | --- |
| **ローカル** | 自分のBest5の順位・スコア |
| **グローバル** | 世界のBest100の順位・名前・スコアと、自分の最高スコアの現在順位 |

- 名前はオプションで設定する。未設定は「名無し冒険者」

### 3.6 図鑑
出会った遺物とガーディアンを記録する収集要素。

## 4. アカウント

### 4.1 アカウント引き継ぎ
初回起動時に匿名アカウントで自動ログインする。ログインは必須。

- ユーザーIDを表示する
- ユーザーIDとパスワードを設定すると、引き継ぎと複数端末での利用ができる

### 4.2 中断
アプリを終了すると進行中のランは破棄する。

### 4.3 アカウント削除
削除するとコイン・ジェム・解放状況・図鑑・ベストスコア・ランキング登録済みのスコアを消す。

## 5. 非機能要件

### 5.1 対応プラットフォーム・言語
iOS。日本語。

### 5.2 通信
プレイ中は通信しない。データの保存・取得と広告表示にのみ通信する。

| タイミング | 用途 | 失敗時 |
| --- | --- | --- |
| 起動時 | ログイン・ユーザーデータ・マスターデータの取得 | エラーを出し再接続を促す |
| ランキング登録 | ランのデータの保存 | 再接続 / 登録せずに終了を選ばせる |
| ジェム購入・遺物パッケージ購入・モード解放 | DBの更新 | 再接続 / タイトルに戻るを選ばせる |
| バナー広告 | 表示 | そのまま動作する |
| リワード広告 | 表示 | 報酬なしで進む / タイトルに戻るを選ばせる |
| 動画広告 | 表示 | エラーを出し、コインを与えずタイトルに戻す |

### 5.3 不正防止
スコアはサーバで検証してからランキングに登録する。

- ランのデータの一部をサーバで作成・保存し、申告スコアと照合する
- 不正ユーザーには警告を出す。5回以上不正したユーザーはサイレントBAN（ランキングからすべて除外）する
