# ユビキタス言語 (Ubiquitous Language)

## 1. ゲーム進行

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| ラン | `Run` | 1回開始してから終了（クリアまたは眠り）するまでの1セッション |
| フロア | `Floor` | ランの区切り。1フロアで決まった数の問題を解く |
| 問題 | `Question` | 1問の計算問題。式と正答を持つ |
| 解答 | `Answer` | プレイヤーが1問に対して提出した値 |
| 正誤判定 | `Judgement` | 1問ごとに正解か不正解かを決めること。時間切れは不正解 |
| クリア | `Clear` | そのモードの全問題を解き終えてランが終了すること |
| 眠り | `Sleep` | 意識が0になり、目覚めの鈴を使わない・残っていないためにランが終了すること |

## 2. ゲーム状態

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| 意識 | `Consciousness` | 不正解のたびに減り、0になると眠る値 |
| 目覚めの鈴 | `WakingBell` | 眠ったときに目を覚まさせる道具。使うと失われる |
| 目覚め | `Awakening` | 目覚めの鈴で眠りから覚めてランを再開すること。スコアが減り、意識が戻る |
| 連続正解 | `ConsecutiveCorrect` | 連続して正解した数。スコアの倍率に使う |
| 正答率 | `AccuracyRate` | そのランで出題された問題のうち正解した割合 |
| 制限時間 | `TimeLimit` | 1問あたりの時間。プレイ形式ごとに決まる |

## 3. スコア

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| スコア | `Score` | 正解で積み上がる得点。ランキングの順位に使う |
| 加算項目 | `AdditiveFactor` | 1問のスコアに足される要素 |
| 倍率項目 | `MultiplierFactor` | 加算項目の合計に掛けられる要素 |
| ベース | `BaseScore` | 正解1問ごとの固定点（加算項目） |
| 速度ボーナス | `SpeedBonus` | 制限時間の残りに応じた点（加算項目） |
| クリアボーナス | `ClearBonus` | クリア時にラン全体のスコアへ加算される点 |
| スコアの確定 | `ScoreFinalization` | ラン終了時にスコアが決まること。確定したスコアをランキングに登録する |
| ベストスコア | `BestScore` | ボードごとの最高スコア |

## 4. モード・難易度・プレイ形式

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| ストーリーモード | `StoryMode` | あかねのストーリーを展開するモード。ランキングに反映しない |
| スコアモード | `ScoreMode` | スコアを競うモードの総称 |
| モード | `Mode` | 1ランの構成（問題数・フロア数・遺物の有無）を決める区分 |
| 難易度 | `Difficulty` | 出題範囲を決める区分 |
| プレイ形式 | `PlayFormat` | 解答の入力方法。アプリ全体の設定として切り替える |

| 区分 | 日本語 → 英語 |
| --- | --- |
| モード | お手軽 `Casual` / 通常 `Standard` / 長旅 `LongJourney` / 遺物なし `NoRelic` / エンドレス `Endless` |
| 難易度 | 簡単 `Easy` / 普通 `Normal` / 難しい `Hard` / 鬼難 `Nightmare` |
| プレイ形式 | 4択形式 `FourChoice` / 入力形式 `Input` |

## 5. 遺物

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| 遺物 | `Relic` | フロアの開始時に獲得し、そのランの間だけ効果を発揮するもの |
| 遺物選択 | `RelicSelection` | フロアの開始時に提示された遺物から1つを選ぶこと |
| レアリティ | `Rarity` | 遺物の希少度。出現のしやすさを決める |
| 効果の種別 | `EffectType` | 遺物の効果が何に作用するかの分類 |
| 遺物パッケージ | `RelicPackage` | ショップで購入できる遺物の集合。購入するとラン中に出現する |

| 区分 | 日本語 → 英語 |
| --- | --- |
| レアリティ | ノーマル(★) `Normal` / レア(★★) `Rare` / スーパーレア(★★★) `SuperRare` |
| 効果の種別 | スコア `Score` / 制限時間 `TimeLimit` / 意識 `Consciousness` / 連続正解 `ConsecutiveCorrect` / 問題 `Question` / ガーディアン `Guardian` / フロア `Floor` |

## 6. ガーディアン

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| ガーディアン | `Guardian` | 各フロアに登場し問題を出す存在。そのフロアの問題を解き終えると倒される |
| 能力 | `Ability` | 一部のガーディアンが持つ、ランに影響を与える作用 |

## 7. プレイヤーと永続データ

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| プレイヤー | `Player` | アプリの利用者。ゲーム内のデータはすべてプレイヤーに紐づく |
| アカウント | `Account` | プレイヤーを識別する単位。初回起動時に匿名で作られ、ユーザーIDとパスワードを設定すると引き継げる |
| ユーザーID | `UserId` | アカウントを識別する文字列。画面に表示し、引き継ぎに使う |
| コイン | `Coin` | 1ラン終えると手に入る通貨 |
| ジェム | `Gem` | 課金で手に入る通貨 |
| 解放 | `Unlock` | コインまたはジェムでモードや難易度を遊べるようにすること |
| 図鑑 | `Codex` | 出会った遺物とガーディアンの記録 |

## 8. ランキング

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| ランキング | `Leaderboard` | スコアを順位づけした一覧 |
| ボード | `Board` | ランキングを分ける単位。モード × 難易度 × プレイ形式 |
| 集計期間 | `Period` | 全期間 `AllTime` / ウィークリー `Weekly` / デイリー `Daily` |
| ローカルランキング | `LocalLeaderboard` | ボードごとの自分のスコア上位5件 |
| グローバルランキング | `GlobalLeaderboard` | ボードごとの世界の上位100件と、自分のベストスコアの現在順位 |
| スコアエントリ | `ScoreEntry` | ランキングに登録される1件のスコア記録 |
| 表示名 | `DisplayName` | ランキングに表示する名前。未設定は「名無し冒険者」 |

## 9. 課金・広告

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| 課金 | `Billing` | 実際のお金でジェムを手に入れること |
| 購入 | `Purchase` | コインまたはジェムで商品を手に入れること |
| ショップ | `Shop` | 遺物パッケージを購入する場所 |
| 広告解除 | `AdRemoval` | すべての広告を非表示にする商品。視聴で得られる効果は受け取れる |
| バナー広告 | `BannerAd` | 画面下部に常時表示する広告 |
| 動画広告 | `VideoAd` | 1ラン終了後に視聴する広告。視聴するとコインが手に入る |
| リワード広告 | `RewardedAd` | 目覚めの鈴を使うときに視聴する広告 |

## 10. データ・不正防止

| 日本語 | 英語 | 定義 |
| --- | --- | --- |
| マスターデータ | `MasterData` | 遺物・ガーディアン・難易度・スコア係数などの定義値。クライアントとサーバが同じものを参照する |
| ランのデータ | `RunData` | 1回のランの記録。スコア検証とランキング登録に使う |
| スコア検証 | `ScoreValidation` | サーバでランのデータからスコアを再計算し、申告値と突き合わせること |
| 不正検知 | `CheatDetection` | スコア検証の結果が一致しないことを検出すること |
| 警告 | `Warning` | 不正検知時にプレイヤーへ通知すること |
| サイレントBAN | `SilentBan` | 不正を繰り返したプレイヤーを、通知せずにランキングから除外すること |

## 11. 世界観の固有名詞

| 日本語 | 定義 |
| --- | --- |
| あかね | 主人公。冒険家 |
| 計算迷宮 アリスメア | 舞台となる迷宮。作中では「アリスメア」と略す |
| 理の宝玉 | あかねが求める宝玉。万物の理が封じられている |
| 眠りの霧 | 不正解や時間切れで部屋に広がる霧。充満すると眠る |
