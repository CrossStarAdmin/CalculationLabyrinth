# 06 ランキング画面(leaderboard)

![ランキング画面](./screen-image-design/06-leaderboard/main.png)
※画像はイメージ。

## 1. 概要
- スコアモードのランキングを、ボード・集計期間・ローカル / グローバルを切り替えて表示する（要件定義 3.5）

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ランキングを取得する | システム | ランキング画面に遷移したとき | 選ばれているボードと集計期間のランキングを取得して表示する |
| 表示するボードを切り替える | ユーザー | モード・難易度・プレイ形式を選び直す | 選び直したボードのランキングを取得して表示する |
| 集計期間を切り替える | ユーザー | 全期間 / ウィークリー / デイリーを選ぶ | 選んだ集計期間のランキングを取得して表示する |
| ローカルとグローバルを切り替える | ユーザー | 切り替えタブをタップ | 選んだ方のランキングを表示する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 戻るボタンをタップ | スタートメニュー画面 |

## 4. 取得要素
| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ローカルランキング情報 | 自分のスコア上位5件（順位・スコア） | ランキングを取得するとき |
| グローバルランキング情報 | 世界の上位100件（順位・名前・スコア）と自分のベストスコアの現在順位 | ランキングを取得するとき |

## 5. 送信要素
なし

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ランキングが取れない | 「取得できません。」と表示して進行を続ける |
