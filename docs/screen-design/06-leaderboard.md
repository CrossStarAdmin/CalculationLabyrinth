# 06 ランキング画面(leaderboard)

![ランキング画面](./screen-image-design/06-leaderboard/main.png)
※画像はあくまでもイメージです。

## 1. 概要
- スコアモードのランキングを表示する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ランキングを取得する | システム | ランキング画面に遷移したとき | 選ばれているボードと集計期間のランキングを取得して表示する |
| 表示するボードを切り替える | ユーザー | モード・難易度・プレイ形式を選び直す | 選び直したボードのランキングを取得して表示する |
| 集計期間を切り替える | ユーザー | 全期間 / ウィークリー / デイリーを選ぶ | 選んだ集計期間のランキングを取得して表示する |
| ローカルとグローバルを切り替える | ユーザー | 切り替えタブをタップ | 選んだ方のランキングを表示する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 戻るボタンをタップ | スタートメニュー画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ローカルランキング情報 | 該当ボード・集計期間での自分のスコア上位5件（順位とスコア） | ランキングを取得するとき |
| グローバルランキング情報 | 該当ボード・集計期間での世界の上位100件（順位・名前・スコア）と、自分のベストスコアの現在順位 | ランキングを取得するとき |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| なし

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ランキングが取れない | 「取得できません。」と表示。エラーは出さず、進行自体に問題はない |

## 7. 細かな仕様
### ランキングの単位について
- ランキングはボード（モード × 難易度 × プレイ形式）ごとに分かれる
- さらに集計期間（全期間 / ウィークリー / デイリー）ごとに分かれる

### 表示名について
- 表示名が未設定のプレイヤーは「名無し冒険者」と表示する

### 未定
- ランの詳細（正答率など）をランキングに表示するかどうか（要件定義 3.5.1 / 3.5.2）
- 画面を開いたときに最初に選ばれているボードと集計期間
