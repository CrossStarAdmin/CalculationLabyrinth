# 07 図鑑画面(codex)

![図鑑画面](./screen-image-design/07-codex/main.png)
※画像はあくまでもイメージです。

## 1. 概要
- 出会った遺物とガーディアンを確認する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| 図鑑を表示する | システム | 図鑑画面に遷移したとき | 遺物とガーディアンの一覧を、出会ったかどうかが分かる形で表示する |
| 遺物とガーディアンを切り替える | ユーザー | 切り替えタブをタップ | 選んだ方の一覧を表示する |
| 詳細を見る | ユーザー | 一覧の項目をタップ | その遺物 / ガーディアンの詳細を表示する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 戻るボタンをタップ | スタートメニュー画面 |

## 7. 細かな仕様
### 図鑑の情報について
- 遺物とガーディアンの一覧はマスターデータから読む
- 出会ったかどうかの記録はユーザーデータに含まれる
- どちらもアプリ起動時のタイトル画面で取得しているので、ローカルから読む

### 図鑑の更新について
- 出会った遺物とガーディアンの記録は、ランが終了したときにゲーム画面から送信される（04 ゲーム画面）
