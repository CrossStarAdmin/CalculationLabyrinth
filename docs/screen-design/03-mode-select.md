# 03 モード / 難易度選択画面(mode-select)

![モード / 難易度選択画面](./screen-image-design/03-mode-select/main.png)
※画像はイメージ。

## 1. 概要
- スコアモードで遊ぶモードと難易度を選ぶ。未解放のモード・難易度を解放する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| モード一覧 / 難易度情報を取得 | システム | モード / 難易度選択画面に遷移 | モード一覧 / 難易度情報を取得する |
| 遊ぶモードを選ぶ | ユーザー | 遊びたいモードのボタンをタップ | モードの詳細と難易度を表示する |
| 自己ベストを取得 | システム | モードが選ばれた | そのモードの難易度ごとの自己ベストを取得する |
| 難易度を選ぶ | ユーザー | 遊びたい難易度のボタンをタップ | その難易度で遊ぶ前提で進む |
| モードを解放する | ユーザー | 未解放のモードをタップ | モードと、その簡単・普通を解放する。成功したらアラートを表示する |
| 難易度を解放する | ユーザー | 未解放の難易度をタップ | 難易度を解放する。成功したらアラートを表示する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 挑戦するボタンをタップ | ゲーム画面 |
| 戻るボタンをタップ | スタートメニュー画面 |

## 4. 取得要素
| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ベストスコア | 選んだモードの難易度ごとの自己ベストスコア | モードが選ばれたとき |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| モードの解放 | 解放するモードと支払い通貨（コイン / ジェム） | 購入の確認で「はい」をタップしたとき |
| 難易度の解放 | 解放する難易度と支払い通貨（コイン / ジェム） | 購入の確認で「はい」をタップしたとき |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ベストスコアが取れない | 「取得できません。」と表示して進行を続ける |
| モードの解放に失敗 | アラートで「モードの解放に失敗しました」と表示。コイン・ジェムを元に戻す |
| 難易度の解放に失敗 | アラートで「難易度の解放に失敗しました」と表示。コイン・ジェムを元に戻す |
| コイン・ジェムが足りない | アラートで「コインが足りません」「ジェムが足りません」と表示する |

## 7. 細かな仕様
- モード・難易度はタイトル画面で取得済みのローカルデータを使う
- 解放は、支払い通貨の選択と購入確認を経て実行する
