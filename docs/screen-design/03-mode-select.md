# 03 モード / 難易度選択画面(mode-select)

![モード / 難易度選択画面](./screen-image-design/03-mode-select/main.png)
※画像はあくまでもイメージです。

## 1. 概要
-スコアモードについて、遊ぶゲームと難易度を選択する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| モード一覧 / 難易度情報を取得 | システム | モード / 難易度選択画面に遷移 | モード一覧 / 難易度情報を取得する |
| 遊ぶモードを選ぶ | ユーザー | 遊びたいモードのボタンをタップ | 遊びたいモードの詳細と難易度が出てくる |
| 自己ベストを取得 | システム | 該当のモードが選ばれた | 該当モードのそれぞれの難易度の自己ベストを取得する |
| 難易度を選ぶ | ユーザー | 遊びたい難易度のボタンをタップ | 該当難易度で遊ぶこと前提で進む |
| モードを解放する | ユーザー | 解放されていないモードをタップ | 解放されていないモードが解放される。難易度は簡単と普通が解放される。成功したらアラートが表示。 |
| 難易度を解放する | ユーザー | 解放されていない難易度をタップ | 解放されていない難易度が解放される。成功したらアラートが表示。 |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 挑戦するボタンをタップ | ゲーム画面 |
| 戻るボタンをタップ | スタートメニュー画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| モード・難易度に沿ったベストスコア | 選んだモードの、難易度ごとの自己ベストスコア | モードが選ばれたとき |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| モードの解放 | 解放するモードと、支払いに使う通貨（コイン / ジェム） | 購入の確認で「はい」をタップしたとき |
| 難易度の解放 | 解放する難易度と、支払いに使う通貨（コイン / ジェム） | 購入の確認で「はい」をタップしたとき |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ベストスコアが取れない | 「取得できません。」と表示。エラーは出さず、信仰自体に問題はない。 |
| モードの解放に失敗 | アラートで「モードの解放に失敗しました」と表示。解放しない。コイン・ジェムは元に戻る |
| 難易度の解放に失敗 | アラートで「難易度の解放に失敗しました」と表示。解放しない。コイン・ジェムは元に戻る |
| 解放に必要なコイン・ジェムが足りない | アラートで「コインが足りません」「ジェムが足りません」と表示。解放しない |

## 7. 細かな仕様
### モード・難易度の取得
- モードや難易度はタイトル画面で取得しています。なのでローカルから取得することになります。

### モード・難易度の解放について
- モードや難易度の解放はコインかジェムを利用することで解放されます
- どちらで購入するのか、本当に購入していいのかを確認後に購入できます。
- 具体的な値段については決まっていません（別資料作成予定）
