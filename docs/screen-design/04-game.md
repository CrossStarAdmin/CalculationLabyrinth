## 1. 概要
- 実際のゲーム画面

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| 遊び方を表示する | システム | ゲーム画面に遷移したとき | 遊び方画像を見せる |
| ゲームを始める | ユーザー | 遊び方画像を閉じる | 該当モードのゲームを始める |
| ゲームをポーズする | ユーザー・システム | ポーズボタンを押す・アプリが閉じられる | ポーズ画面を表示し、再開できるようにする |
| BGMを調整する | ユーザー | 設定ボタンを押し、BGMの音量を操作する | BGMの音量を更新する |
| SEを調整する | ユーザー | 設定ボタンを押し、SEの音量を操作する | SEの音量を更新する |
| あかねが眠る | システム | 意識が0になる | 目覚めの鈴が残っていれば、使うかどうかを確認する |
| 広告をみて目覚める | ユーザー | 目覚めの鈴を使う | リワード広告を視聴後、スコアを70%にして意識を2戻し、ゲームを再開する |
| ラン情報を送信する | システム | ゲームが終了する | ラン結果情報をサーバーに送信する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| ゲーム終了 | 結果画面 |
| ポーズ画面のメニューに戻るボタンを押す | スタートメニュー画面 |
| ゲーム終了（ストーリー）|ストーリー画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ランID | ランを識別するID | ラン開始情報の送信後 |
| シード | 問題・遺物・ガーディアンの生成に使う乱数の種 | ラン開始情報の送信後 |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| ラン開始情報 | 該当ランの初期情報 | ゲームを始める前 |
| ラン結果情報  | 該当ランの結果 | ゲームが終了した後 |
| 解放するガーディアン情報 | そのランで初めて出会ったガーディアン | ゲームが終了した後 |
| 解放する遺物情報 | そのランで初めて出会った遺物 | ゲームが終了した後 |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ラン開始情報を送れない | エラーモーダルに「ゲームを開始できません。」と表示。スタートメニューに戻るボタンと再接続ボタンを表示 |
| ラン終了情報を送れない | エラーモーダルに「スコアを送信できませんでした。」と表示。スタートメニューに戻るボタンと再接続ボタンを表示。データが送れない場合、保存できないことも記入する |

## 7. 細かな仕様
### ラン開始情報について
- ゲームを始める前に、モード・難易度・プレイ形式をサーバーに送る
- サーバーは **ランID** と **シード（乱数の種）** を返し、ランID・シード・開始時刻を保存する
- クライアントはシードを基に、出題する問題・提示する遺物の候補・登場するガーディアンをローカルで作成する
- サーバーは同じシードから同じものを再現できるため、問題や遺物のデータ自体は送受信しない

#### 検証のしくみ
- ラン結果情報（各問の正誤と残り時間、選んだ遺物、申告スコア）を受け取ったサーバーは、シードから同じランを再現してスコアを再計算し、申告スコアと照合する
- 一致しない場合は不正とみなす（要件定義 5.3）

#### これで防げること
- 簡単な問題ばかり出させる、強い遺物だけ提示させるといった出題の操作
- 正誤や残り時間と合わないスコアの申告
- 残り時間が制限時間を超えている、問題数が合わない、開始から終了までの実時間が短すぎる、といったありえない値

#### これでは防げないこと
- クライアントを改造して「全問正解・残り時間ほぼ満タン」を送られた場合、計算としては正しいため通る
- これを弾くには正答率や解答速度の傾向を見る必要がある（要件定義 5.3 のサイレントBAN）

### ゲームについて
- 基本ゲームについては以下をループする
    - 遺物選択モード
        - 提示された３つの遺物の中から１つの遺物を選択する
    - 計算モード
         - ガーディアンによって全20問出されるので、順番に解いていく
- ゲームの細かな仕様については別資料で展開する

### ゲームの中断について
- ランを保存して後から再開する機能は用意しない
- 他のアプリに切り替えるなどでバックグラウンドに移った場合は、ポーズ画面にして再開できるようにする
- アプリが完全に終了し、タイトル画面から起動し直しになった場合はランのデータはすべて消える

### ポーズについて
- ポーズ中は制限時間は止まる
- ポーズ中は問題を隠す
