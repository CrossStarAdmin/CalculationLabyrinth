# 08 ショップ画面(shop)

![ショップ画面](./screen-image-design/08-shop/main.png)
※画像はあくまでもイメージです。

## 1. 概要
- 遺物パッケージ・ジェム・広告解除を購入する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| 商品一覧を表示する | システム | ショップ画面に遷移したとき | 購入できる商品と、所持しているコイン・ジェムを表示する |
| 遺物パッケージを購入する | ユーザー | 遺物パッケージの購入ボタンをタップ | 支払いに使う通貨を選び、確認後に購入する |
| ジェムを購入する | ユーザー | ジェムの購入ボタンをタップ | ストアの課金処理を行い、完了後にジェムを加算する |
| 広告解除を購入する | ユーザー | 広告解除の購入ボタンをタップ | ストアの課金処理を行い、完了後に広告を非表示にする |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 戻るボタンをタップ | スタートメニュー画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ストアの商品情報 | ジェム・広告解除の価格など、ストアから取得する情報 | ショップ画面に遷移したとき |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| 遺物パッケージの購入 | 購入するパッケージと、支払いに使う通貨（コイン / ジェム） | 購入の確認で「はい」をタップしたとき |
| 課金のレシート | ストアの課金完了時に発行されるレシート | ジェム・広告解除の課金が完了したとき |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ストアの商品情報が取れない | エラーモーダルに「商品を表示できませんでした。」と表示。再接続ボタンとメニューに戻るボタンを表示 |
| 購入に必要なコイン・ジェムが足りない | アラートで「コインが足りません」「ジェムが足りません」と表示。購入しない |
| 遺物パッケージの購入に失敗 | エラーモーダルに「購入に失敗しました。」と表示。コイン・ジェムは元に戻る |
| 課金に失敗 | エラーモーダルに「購入を完了できませんでした。」と表示 |
| レシートの検証に失敗 | エラーモーダルに「購入を確認できませんでした。」と表示。問い合わせを案内する |

## 7. 細かな仕様
### 購入について
- 遺物パッケージはコインかジェムで購入する
- ジェムと広告解除はストアの課金で購入する
- 課金の対象は、ジェム・広告解除・モード / 難易度の解放（要件定義 3.3）

### 遺物パッケージについて
- 購入したパッケージに入っている遺物は、以降のランで出現するようになる（要件定義 2.4.4）
- 遊びの幅を広げるためのものとし、Pay-to-win にはしない

### 未定
- 具体的な価格（別資料で作成予定）
- すでに購入したパッケージの表示方法
