# 05 結果画面(result)

![結果画面](./screen-image-design/05-result/main.png)
※画像はあくまでもイメージです。

## 1. 概要
- スコアモードの結果を表示する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ローカルランキングの取得 | システム | 結果画面に遷移したとき | 該当ボードのローカルランキングを取得して表示する |
| グローバルランキングの取得 | システム | 結果画面に遷移したとき | 該当ボードのグローバルランキングと自分の現在順位を取得して表示する |
| 広告を見てコインを獲得する | システム | 結果画面から遷移しようとしたとき | 動画広告を表示し、視聴が完了したらコインを加算して遷移する<br>広告解除を購入している場合は広告を表示せずに加算して遷移する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| メニューに戻るボタンを押す | スタートメニュー画面 |
| もう一度遊ぶボタンを押す | ゲーム画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ローカルランキング情報 | 該当モードのローカルのランキング情報（Best5） | 結果画面遷移時 |
| グローバルランキング情報 | 該当モードのグローバルのランキング（Best100）と自分の現在順位 | 結果画面遷移時 |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| ラン終了時のコイン枚数更新 | 現在のコイン数にラン終了時のコイン数を足した数 | 動画広告の視聴が完了したとき（広告解除の購入者は遷移しようとしたとき） |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ローカル / グローバルランキングが取れない | 「取得できません。」と表示。エラーは出さず、進行自体に問題はない |
| コイン取得枚数の更新に失敗 | エラーモーダルに「コインを獲得できませんでした。」と表示。再接続ボタンとメニューに戻るボタンを表示。メニューに戻る場合コインを獲得できないことを警告。 |
| 動画広告が取得できない | エラーモーダルに「広告を表示できませんでした。」と表示。再接続ボタンとメニューに戻るボタンを表示。メニューに戻る場合はコインを獲得できないことを警告。 |

※メニューに戻るボタンではなく、もう一度遊ぶボタンをタップしていた場合は、メニューに戻るボタンではなくもう一度遊ぶボタンを表示する

## 7. 細かな仕様
### コインの獲得について
- コインは結果画面から遷移するときに獲得する
- メニューに戻る場合も、もう一度遊ぶ場合も、遷移の前に動画広告を表示する
- 広告の視聴が完了してからコインを加算し、遷移する
- 広告解除を購入している場合は、広告を表示せずにコインを加算して遷移する
