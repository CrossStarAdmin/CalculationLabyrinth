# 05 結果画面(result)

![結果画面](./screen-image-design/05-result/main.png)
※画像はイメージ。

## 1. 概要
- スコアモードの結果とランキングを表示する。遷移時に動画広告を挟んでコインを付与する

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ローカルランキングの取得 | システム | 結果画面に遷移したとき | 該当ボードのローカルランキングを取得して表示する |
| グローバルランキングの取得 | システム | 結果画面に遷移したとき | 該当ボードのグローバルランキングと自分の現在順位を取得して表示する |
| 広告を見てコインを獲得する | システム | 結果画面から遷移しようとしたとき | 動画広告を表示し、視聴完了後にコインを加算して遷移する<br>広告解除の購入者は広告を表示せずに加算して遷移する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| メニューに戻るボタンを押す | スタートメニュー画面 |
| もう一度遊ぶボタンを押す | ゲーム画面 |

## 4. 取得要素
| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ローカルランキング情報 | 該当ボードのBest5 | 結果画面遷移時 |
| グローバルランキング情報 | 該当ボードのBest100と自分の現在順位 | 結果画面遷移時 |

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| コイン枚数の更新 | 現在のコイン数 + ランで獲得したコイン数 | 動画広告の視聴完了時（広告解除の購入者は遷移時） |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| ランキングが取れない | 「取得できません。」と表示して進行を続ける |
| コインの更新に失敗 | エラーモーダルに「コインを獲得できませんでした。」と表示。再接続ボタンと戻るボタンを表示。戻る場合はコインを獲得できないことを警告 |
| 動画広告が取得できない | エラーモーダルに「広告を表示できませんでした。」と表示。再接続ボタンと戻るボタンを表示。戻る場合はコインを獲得できないことを警告 |

## 7. 細かな仕様
- エラーモーダルの戻るボタンは、ユーザーが押した遷移ボタン（メニューに戻る / もう一度遊ぶ）に合わせる
