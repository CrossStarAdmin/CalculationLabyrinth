# 01 タイトル画面(title)

![タイトル画面](./screen-image-design/01-title/main.png)

![エラーモーダル](./screen-image-design/01-title/error-modal.png)
※画像はイメージ。

## 1. 概要
- サイレントログインとマスターデータのダウンロードを行う
- ユーザーIDを確認できる

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| サイレントログインをする | システム | アプリを起動する | 端末に保存した認証情報でサイレントログインし、ユーザーデータを取得する |
| マスターデータを取得する | システム | アプリを起動する | サーバーからマスターデータを取得する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| スタートボタンをタップ | スタートメニュー画面 |

## 4. 取得要素
| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ユーザーID | 問い合わせに使うユニークなID | サイレントログイン時 |
| ユーザーデータ | 名前・コイン・ジェム・モード/難易度の解放状況・ガーディアン/遺物の解放済みIDリスト・所持遺物パッケージ・ベストスコア | サイレントログイン後 |
| マスターデータ | モード・難易度・遺物・ガーディアン・問題形式・スコアの各項目の値 | アプリ起動時 |

## 5. 送信要素
なし

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| 通信に失敗した | エラーモーダルを表示し、再接続を促す |

## 7. 細かな仕様
- 初回起動時は匿名アカウントを作成し、認証情報を端末に保存する。2回目以降は保存した認証情報でトークンを発行する
- ログインとマスターデータ取得は起動時のみ行う
- サイレントログインとマスターデータ取得が完了したらスタートボタンを表示する。スタートメニューから戻った場合は即表示する
