# 10 ストーリー画面(story)

![ストーリー画面](./screen-image-design/10-story/main.png)
※画像はあくまでもイメージです。

## 1. 概要

- ストーリーを展開するのに利用する

## 2. ユースケース

| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ストーリーを表示する |  |  |  |

## 3. 画面遷移

| 操作 | 遷移先 |
| ---- | ----- |
| ゲームに進む | ストーリー用ゲーム画面 |

## 4. 取得要素

| 要素 | 内容 | 取得条件 |
| --- | --- | --- |
| ストーリー | 該当する段階のストーリーを取得 | ストーリー画面起動時 |

## 5. 送信要素

| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| ストーリーフラグ | ストーリーフラグ更新 | ストーリー用ゲーム画面遷移前 |

## 6. 例外処理

| 条件 | システムの対応 |
| ---- | ------------ |
| ストーリーの取得ができない | エラーモーダルに「ストーリーを取得できませんでした」と表示 |
