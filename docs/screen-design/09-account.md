# 09 アカウント画面(account)

![アカウント画面](./screen-image-design/09-account/main.png)
※画像はイメージ。

## 1. 概要
- ユーザーIDの確認、引き継ぎの設定・実行、アカウントの削除、問い合わせを行う

## 2. ユースケース
| ユースケース | アクター | トリガー | 処理 |
| ----------- | ------- | ------- | ---- |
| ユーザーIDを表示する | システム | アカウント画面に遷移したとき | 現在のユーザーIDを表示する |
| 引き継ぎを設定する | ユーザー | 引き継ぎ設定ボタンをタップ | ユーザーIDとパスワードを入力し、いまのアカウントに紐づける |
| 引き継ぐ | ユーザー | 引き継ぎボタンをタップ | 「いまのデータは失われます」と確認後、ユーザーIDとパスワードを入力してそのアカウントでログインし直す |
| アカウントを削除する | ユーザー | アカウント削除ボタンをタップ | 確認後にアカウントとデータを削除する（要件定義 4.3） |
| 問い合わせる | ユーザー | 問い合わせボタンをタップ | 問い合わせ先を表示する |

## 3. 画面遷移
| 操作 | 遷移先 |
| ---- | ----- |
| 戻るボタンをタップ | スタートメニュー画面 |
| 引き継ぎが完了する | タイトル画面 |
| アカウントの削除が完了する | タイトル画面 |

## 4. 取得要素
なし

## 5. 送信要素
| 要素 | 内容 | 送信条件 |
| ---- | ---- | ------- |
| 引き継ぎ設定情報 | ユーザーIDとパスワード | 引き継ぎ設定の確認で「はい」をタップしたとき |
| 引き継ぎ情報 | ユーザーIDとパスワード | 引き継ぎの確認で「はい」をタップしたとき |
| アカウント削除 | 削除するアカウント | 削除の確認で「はい」をタップしたとき |

## 6. 例外処理
| 条件 | システムの対応 |
| ---- | ------------ |
| 引き継ぎの設定に失敗 | エラーモーダルに「設定できませんでした。」と表示。再接続ボタンを表示 |
| ユーザーIDまたはパスワードが違う | アラートで「ユーザーIDまたはパスワードが違います」と表示する |
| アカウントの削除に失敗 | エラーモーダルに「削除できませんでした。」と表示。再接続ボタンを表示 |

## 7. 細かな仕様
- ユーザーIDはタイトル画面で取得済みのローカルデータから読む
- 引き継ぎ設定は、いまのアカウントに認証手段を紐づける。データはそのまま残り、別の端末でユーザーIDとパスワードを入力すると同じアカウントを使える
- 引き継ぎを実行すると、いまの端末のアカウントは切り離される
- 削除後はタイトル画面に戻り、新しい匿名アカウントを作成する
