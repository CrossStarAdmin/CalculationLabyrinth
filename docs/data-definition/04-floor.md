# 04 フロア データ定義

## 1. 概要

フロアのデータはアプリのメモリで持つ。サーバーにも端末にも保存しない。

| 保存場所 | 保存するデータ |
| --- | --- |
| ローカル（メモリ） | シードから生成した遺物の候補・ガーディアン・問題 |

## 2. ローカル側のデータ

### 2.1 データ構造

```
floors {
    floors: {
        id: string
        floor_number: number
        relic_ids: string[]
        guardian_id: string
        questions {
            question_number: number
            question_type_id: string
            question: string
            answer: number
            timer: number
            score: number
        }[]
    }[]
}
```

### 2.2 初期値

ラン開始時は空配列。フロアに入るときに、そのフロアを生成して追加する。

```json
{
    "floors": []
}
```

追加するフロアの例

```json
{
    "id": "floor_【ラン内で1からのauto incrementな数字】",
    "floor_number": "【ラン内で1からの番号】",
    "relic_ids": ["【シードから選んだ遺物のID】", "…", "…"],
    "guardian_id": "【シードから選んだガーディアンのID】",
    "questions": [
        {
            "question_number": "【ラン通しての通し番号】",
            "question_type_id": "【問題種別のID】",
            "question": "3 + 5",
            "answer": 8,
            "timer": 8,
            "score": 100
        }
    ]
}
```

### 2.3 各項目の説明

どの項目も、フロアに入るときにシードから生成して入れ、そのあとは変えない。

#### floors[].id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | フロアを識別するID |
| 制約 | `floor_【auto incrementな数字】` の形式。ラン内で1から採番する |
| 初期値 | 生成時に採番した値 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].floor_number

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ラン内で何番目のフロアか |
| 制約 | 1始まりの整数。ラン内で重複しない |
| 初期値 | 生成時の番号 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].relic_ids

| 項目 | 内容 |
| --- | --- |
| 型 | string[] |
| 説明 | 遺物選択で提示する遺物の候補のID |
| 制約 | マスターデータの遺物に存在するID。3件 |
| 初期値 | シードから選んだ遺物のID |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].guardian_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | フロアに登場するガーディアンのID |
| 制約 | マスターデータのガーディアンに存在するID |
| 初期値 | シードから選んだガーディアンのID |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].question_number

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ラン通しての問題の通し番号 |
| 制約 | 1始まりの整数。ラン内で重複しない |
| 初期値 | 生成時の番号 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].question_type_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 問題種別のID |
| 制約 | マスターデータの問題種別に存在するID |
| 初期値 | シードから選んだ問題種別のID |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].question

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 問題の式。「= ?」は含めず、表示側で付ける |
| 制約 | 例: `3 + 5` |
| 初期値 | シードから生成した式 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].answer

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 問題の正答 |
| 制約 | 整数 |
| 初期値 | `question` の式の計算結果 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].timer

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 問題の制限時間（秒） |
| 制約 | 0より大きい |
| 初期値 | マスターデータの制限時間 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |

#### floors[].questions[].score

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 問題の基礎点 |
| 制約 | 0以上の整数 |
| 初期値 | マスターデータの基礎点 |
| 値の変更 | 不変 |
| 書き権限 | アプリ |
