# 05 ローカルランク データ定義

## 1. 概要

ローカルランキング専用のデータは保存しない。`runs`（03-run.md）から取得する。

| 保存場所 | 保存するデータ |
| --- | --- |
| なし | `runs` を読んで組み立てる |

順位は保存せず、取得時にスコアの高い順で決める。

## 2. 取得方法

### 2.1 絞り込み条件

| 項目 | 条件 |
| --- | --- |
| `user_profile_id` | ログイン中の uid |
| `mode_id` / `mode_difficulty_level_id` / `play_format` | 表示するボード |
| `status` | `cleared` / `failed` のみ（`playing` / `invalid` は除く） |

### 2.2 集計期間ごとの取り方

| 集計期間 | 取り方 |
| --- | --- |
| 全期間 | `score` の高い順に5件取得する |
| ウィークリー | `finished_at` が今週の範囲のランを全件取得し、アプリで `score` の高い順に並べて上位5件にする |
| デイリー | `finished_at` が今日の範囲のランを全件取得し、アプリで `score` の高い順に並べて上位5件にする |

ウィークリー / デイリーは1人・1ボード・1期間あたりの件数が少ないため、並べ替えをアプリで行う。

### 2.3 期間の区切り

- 日本時間（JST）で区切る
- デイリーは 0:00 から翌日 0:00 まで
- ウィークリーは月曜 0:00 から翌週月曜 0:00 まで

### 2.4 権限

`runs` の権限（本人のランのみ読める）の範囲で取得できる。
