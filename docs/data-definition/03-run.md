# 03 ラン データ定義

## 1. 概要

ランのデータはサーバーに保存する。

| 保存場所 | 保存するデータ |
| --- | --- |
| サーバー | 全ランの記録 |

プレイ中の状態はアプリのメモリで持ち、端末には保存しない（04-game.md ゲームの中断について）。

## 2. サーバー側のデータ

- **コレクション名**: `runs`

### 2.1 データ構造

```
runs/{run_id} {
    id: string,
    version: number,
    user_profile_id: string,
    play_format: four-choice | input,
    started_at: datetime,
    finished_at: datetime | null,
    challenge_count: number,
    mode_id: string,
    mode_difficulty_level_id: string,
    seed: string,
    status: playing | cleared | failed | invalid,
    life: number,
    is_used_bell: boolean,
    score: number,
    grant_coin_count: number,
    is_grant_coin: boolean,
    owned_relics: {
        relic_id: string,
        order: number,
    }[],
}
```

### 2.2 初期値

```json
{
    "id": "run_【auto incrementな数字】",
    "version": "【ラン開始時のマスターデータのバージョン】",
    "user_profile_id": "【ラン開始を呼び出したユーザーのuid】",
    "play_format": "【ラン開始時に送られたプレイ形式】",
    "started_at": "【ラン開始時のサーバー時刻】",
    "finished_at": null,
    "challenge_count": "【そのユーザーの何回目のランか】",
    "mode_id": "【ラン開始時に送られたモードのID】",
    "mode_difficulty_level_id": "【ラン開始時に送られた難易度のID】",
    "seed": "【サーバーが発行した乱数の種】",
    "status": "playing",
    "life": 3,
    "is_used_bell": false,
    "score": 0,
    "grant_coin_count": 0,
    "is_grant_coin": false,
    "owned_relics": []
}
```

### 2.3 権限

| 操作 | 許可する対象 | 条件 |
| --- | --- | --- |
| 読み | アプリ | ログイン中の uid が `user_profile_id` と一致する |
| 書き | サーバー（Cloud Functions） | なし |

### 2.4 各項目の説明

#### id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランを識別するID。ドキュメントIDと同じ値 |
| 制約 | `run_【auto incrementな数字】` の形式 |
| 初期値 | 作成時に採番した値 |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### version

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ラン開始時のマスターデータのバージョン。検証時は同じバージョンで再現する |
| 制約 | 配信済みのマスターデータのバージョン |
| 初期値 | ラン開始時のマスターデータのバージョン |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### user_profile_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランを遊んだユーザーのID |
| 制約 | `users` に存在するID |
| 初期値 | ラン開始を呼び出したユーザーのuid |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### play_format

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランの解答の入力方法 |
| 制約 | `four-choice`（4択形式） / `input`（入力形式） |
| 初期値 | ラン開始時に送られたプレイ形式 |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### started_at

| 項目 | 内容 |
| --- | --- |
| 型 | datetime |
| 説明 | ランの開始時刻 |
| 制約 | なし |
| 初期値 | ラン開始時のサーバー時刻 |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### finished_at

| 項目 | 内容 |
| --- | --- |
| 型 | datetime / null |
| 説明 | ランの終了時刻。開始からの実時間が短すぎるランを不正と判定するのに使う |
| 制約 | `started_at` 以降 |
| 初期値 | null |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときのサーバー時刻を入れる |
| 書き権限 | サーバー |

#### challenge_count

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | そのユーザーの何回目のランか。モード・難易度・プレイ形式ごとに数える |
| 制約 | 1以上の整数 |
| 初期値 | ラン開始時に採番した値 |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### mode_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランのモードのID |
| 制約 | マスターデータのモードに存在するID |
| 初期値 | ラン開始時に送られたモードのID |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### mode_difficulty_level_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランの難易度のID |
| 制約 | `mode_id` のモードに属する難易度のID |
| 初期値 | ラン開始時に送られた難易度のID |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### seed

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 問題・遺物の候補・ガーディアンの生成に使う乱数の種 |
| 制約 | 未定（乱数生成器を決めるときに決める） |
| 初期値 | ラン開始時にサーバーが発行した値 |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### status

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランの状態 |
| 制約 | `playing`（プレイ中） / `cleared`（クリア） / `failed`（眠り） / `invalid`（検証で不正と判定） |
| 初期値 | `playing` |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときに `cleared` / `failed` / `invalid` にする。結果が届かなかったランは `playing` のまま残す |
| 書き権限 | サーバー |

#### life

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ラン終了時の意識の残り |
| 制約 | 0以上の整数 |
| 初期値 | 3 |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときに再現結果の値を入れる |
| 書き権限 | サーバー |

#### is_used_bell

| 項目 | 内容 |
| --- | --- |
| 型 | boolean |
| 説明 | 目覚めの鈴を使ったかどうか。SSV の記録と照合する |
| 制約 | なし |
| 初期値 | false |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときに、一度目覚めの鈴を利用していたらtrueにする |
| 書き権限 | サーバー |

#### score

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ランの確定スコア |
| 制約 | 0以上の整数 |
| 初期値 | 0 |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときに入れる。検証が通れば再計算したスコア、`invalid` のときは申告スコアを入れる |
| 書き権限 | サーバー |

#### grant_coin_count

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ラン報酬として付与するコインの数 |
| 制約 | 0以上の整数 |
| 初期値 | 0 |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときにサーバーが計算して入れる。`invalid` のときは 0 のまま |
| 書き権限 | サーバー |

#### is_grant_coin

| 項目 | 内容 |
| --- | --- |
| 型 | boolean |
| 説明 | ラン報酬のコインを付与済みかどうか。付与はランごとに1回だけ受け付ける |
| 制約 | なし |
| 初期値 | false |
| 値の変更 | 結果画面でコインを付与したとき true にする。 |
| 書き権限 | サーバー |

#### owned_relics[].relic_id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランで選んだ遺物のID |
| 制約 | マスターデータの遺物に存在するID |
| 初期値 | なし（空配列） |
| 値の変更 | ゲーム画面でランが終了し、ラン結果を受け取ったときに、選んだ遺物を追加する |
| 書き権限 | サーバー |

#### owned_relics[].order

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 遺物を選んだ順番 |
| 制約 | 1始まりの整数。ラン内で重複しない |
| 初期値 | なし（空配列） |
| 値の変更 | `relic_id` と一緒に追加する |
| 書き権限 | サーバー |
