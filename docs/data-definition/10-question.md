# 10 問題 データ定義

## 1. 概要

問題種別はマスターデータとしてサーバーに保存する。アプリは起動時に取得する（01-title.md）。

| 保存場所 | 保存するデータ |
| --- | --- |
| サーバー | 問題種別 |

## 2. サーバー側のデータ

- **コレクション名**: `question_types`

### 2.1 データ構造

```
question_types/{question_type_id} {
    id: string,
    name: string,
}
```

### 2.2 初期値

管理用スクリプトで投入する。例:

```json
{
    "id": "question_type_1",
    "name": "【問題種別名】"
}
```

### 2.3 権限

| 操作 | 許可する対象 | 条件 |
| --- | --- | --- |
| 読み | アプリ | ログイン中であること |
| 書き | 管理用スクリプト | アプリ・Cloud Functions からは書かない |

### 2.4 各項目の説明

どの項目も管理用スクリプトで投入し、アプリの操作では変わらない。

#### id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 問題種別を識別するID。ドキュメントIDと同じ値 |
| 制約 | `question_type_【auto incrementな数字】` の形式 |
| 初期値 | 投入時に採番した値 |
| 値の変更 | 不変 |
| 書き権限 | 管理用スクリプト |

#### name

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 問題種別の名前 |
| 制約 | なし |
| 初期値 | 投入時の値 |
| 値の変更 | 管理用スクリプトで更新したとき |
| 書き権限 | 管理用スクリプト |
