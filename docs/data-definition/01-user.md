# 01 ユーザー データ定義

## 1. 概要

ユーザーのデータは、サーバーとローカル（端末）に分けて保存する。

| 保存場所 | 保存するデータ |
| --- | --- |
| サーバー | ユーザーの恒久情報、不正されたくないデータ |
| ローカル | BGMやSE等のユーザーの設定値。変えられてもいいデータ |

## 2. サーバー側のデータ

- **コレクション名**: `users`

### 2.1 データ構造

```
users/{user_profile_id} {
    id: string,
    name: string,
    is_ad_removed: boolean,
    coin_amount: number,
    gem_amount: number,
    story_flag: number
}
```

### 2.2 初期値

```json
{
    "id": "【Firebase Authで作成されるID】",
    "name": "名無し冒険者",
    "is_ad_removed": false,
    "coin_amount": 0,
    "gem_amount": 0,
    "story_flag": 0
}
```

### 2.3 権限

| 操作 | 許可する対象 | 条件 |
| --- | --- | --- |
| 読み | アプリ | ログイン中の uid がドキュメントID（`user_profile_id`）と一致する |
| 書き | サーバー（Cloud Functions） | なし |

### 2.4 各項目の説明

#### id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ユーザーを識別するID。ドキュメントIDと同じ値 |
| 制約 | Firebase Authのuid（英数字28文字） |
| 初期値 | FirebaseAuthが自動で作成した値 |
| 生成 | FirebaseAuth |
| 値の変更 | 不変 |
| 書き権限 | サーバー（作成時のみ） |

#### name

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | ランキングに表示する名前 |
| 制約 | 1〜10文字。NGワードを含まない |
| 初期値 | 名無し冒険者 |
| 値の変更 | スタートメニュー画面の名前変更で更新 |
| 書き権限 | サーバー |

#### is_ad_removed

| 項目 | 内容 |
| --- | --- |
| 型 | boolean |
| 説明 | 広告解除を購入済みかどうか |
| 制約 | なし |
| 初期値 | false |
| 値の変更 | ショップ画面で広告解除を購入したとき true にする。false には戻さない |
| 書き権限 | サーバー |

#### coin_amount

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 所持しているコインの数 |
| 制約 | 0以上の整数 |
| 初期値 | 0 |
| 値の変更 | 結果画面でラン報酬を受け取ると増える。モード / 難易度の解放、遺物パッケージの購入で減る |
| 書き権限 | サーバー |

#### gem_amount

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | 所持しているジェムの数 |
| 制約 | 0以上の整数 |
| 初期値 | 0 |
| 値の変更 | ショップ画面でジェムを購入すると増える。モード / 難易度の解放、遺物パッケージの購入で減る |
| 書き権限 | サーバー |

#### story_flag

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | ストーリーの進行段階 |
| 制約 | 0以上の整数 |
| 初期値 | 0 |
| 値の変更 | ストーリー画面からストーリー用ゲーム画面に進むときに増える |
| 書き権限 | サーバー |

## 3. ローカル側のデータ

### 3.1 データ構造

```
users {
    play_format: four-choice | input,
    bgm_volume: number（0~5）,
    se_volume: number（0~5）
}
```

### 3.2 初期値

```json
{
    "play_format": "four-choice",
    "bgm_volume": 4,
    "se_volume": 4
}
```

### 3.3 各項目の説明

#### play_format

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | 解答の入力方法。アプリ全体の設定 |
| 制約 | `four-choice`（4択形式） / `input`（入力形式） |
| 初期値 | `four-choice` |
| 値の変更 | ユーザーが設定を切り替えたとき |
| 書き権限 | アプリ |

#### bgm_volume

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | BGMの音量 |
| 制約 | 0〜5の整数 |
| 初期値 | 4 |
| 値の変更 | スタートメニュー画面のオプション、ゲーム画面の設定で音量を操作したとき |
| 書き権限 | アプリ |

#### se_volume

| 項目 | 内容 |
| --- | --- |
| 型 | number |
| 説明 | SEの音量 |
| 制約 | 0〜5の整数 |
| 初期値 | 4 |
| 値の変更 | スタートメニュー画面のオプション、ゲーム画面の設定で音量を操作したとき |
| 書き権限 | アプリ |
