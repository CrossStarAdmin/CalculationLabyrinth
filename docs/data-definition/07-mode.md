# 07 モード データ定義

## 1. 概要

モード・難易度はマスターデータとしてサーバーに保存する。アプリは起動時に取得する（01-title.md）。

| 保存場所 | 保存するデータ |
| --- | --- |
| サーバー | モードと、モードごとの難易度 |

## 2. サーバー側のデータ

- **コレクション名**: `modes`

### 2.1 データ構造

```
modes/{mode_id} {
    id: string,
    name: string,
    description: string,
    gem_amount: number,
    coin_amount: number,
    floor_count: number | null,
    questions_per_floor: number,
    has_relic: boolean,
    mode_difficulty_levels: {
        id: string,
        name: string,
        description: string,
        difficulty_level: number,
        gem_amount: number,
        coin_amount: number,
    }[]
}
```

### 2.2 初期値

管理用スクリプトで投入する。例:

```json
{
    "id": "mode_1",
    "name": "通常モード",
    "description": "20問*5段階で100問を解ききるモード",
    "gem_amount": 0,
    "coin_amount": 0,
    "floor_count": 5,
    "questions_per_floor": 20,
    "has_relic": true,
    "mode_difficulty_levels": [
        {
            "id": "mode_difficulty_level_1",
            "name": "簡単",
            "description": "加減算のみ、１桁の計算中心",
            "difficulty_level": 0,
            "gem_amount": 0,
            "coin_amount": 0
        }
    ]
}
```

### 2.3 権限

| 操作 | 許可する対象 | 条件 |
| --- | --- | --- |
| 読み | アプリ | ログイン中であること |
| 書き | 管理用スクリプト | アプリ・Cloud Functions からは書かない |

### 2.4 各項目の説明

どの項目も管理用スクリプトで投入し、アプリの操作では変わらない。

#### id

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | モードを識別するID。ドキュメントIDと同じ値 |
| 制約 | `mode_【auto incrementな数字】` の形式 |
| 初期値 | 投入時に採番した値 |
| 値の変更 | 不変 |
| 書き権限 | 管理用スクリプト |

#### name

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | モードの名前 |
| 制約 | なし |
| 初期値 | 投入時の値 |
| 値の変更 | 管理用スクリプトで更新したとき |
| 書き権限 | 管理用スクリプト |

#### description

| 項目 | 内容 |
| --- | --- |
| 型 | string |
| 説明 | モードの説明 |
| 制約 | なし |
| 初期値 | 投入時の値 |
| 値の変更 | 管理用スクリプトで更新したとき |
| 書き権限 | 管理用スクリプト |
